COMP 3500SEF — Full-Stack Architecture & RBAC Security Guide (v4.0)

Upgraded from Prototype to Python Flask REST API + Server-Side SQLite 3 + Session Auth

1. Full-Stack 3-Tier MVC Architecture

Presentation Tier (View)

Forest Teal & Warm Stone HTML5/Tailwind UI calling REST endpoints via async fetch(). Public tracking portal + authenticated staff workspaces.

Backend Tier (Flask API)

Python Flask server enforcing Werkzeug password hashing, HttpOnly session cookies, RBAC (@require_roles), form validation, and the 5-stage State Machine.

Persistence Tier (SQLite 3)

Server-side hk_link_lms.db with 4 normalized tables: users, drivers, shipments, and tracking_history with Foreign Key constraints.

-- SQLite 3 Relational Schema (4 Normalized Tables)
CREATE TABLE drivers (id TEXT PRIMARY KEY, name TEXT, truckId TEXT, routeZone TEXT, phone TEXT, maxCapacityKg REAL);
CREATE TABLE users (id INTEGER PRIMARY KEY AUTOINCREMENT, username TEXT UNIQUE, password_hash TEXT, role TEXT, displayName TEXT, driverId TEXT REFERENCES drivers(id));
CREATE TABLE shipments (id TEXT PRIMARY KEY, senderName TEXT, originDistrict TEXT, receiverName TEXT, receiverPhone TEXT, destAddress TEXT, weightKg REAL CHECK(weightKg > 0), priority TEXT, packageDesc TEXT, status TEXT, driverId TEXT REFERENCES drivers(id), createdAt TEXT, estimatedDelivery TEXT);
CREATE TABLE tracking_history (logId INTEGER PRIMARY KEY AUTOINCREMENT, shipmentId TEXT REFERENCES shipments(id) ON DELETE CASCADE, stage TEXT, timestamp TEXT, location TEXT, note TEXT);
